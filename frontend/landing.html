A note on temporal RAG

A regulation is more than its latest version.

Temporal Retrieval-Augmented Generation (Temporal RAG) brings a date-aware lens to document retrieval. Instead of considering only the newest text, a query can be explored against the versions relevant to a selected point in time.

For banking research, that can help frame questions such as what wording applied before an amendment, what the later text says, and which official document should be reviewed.
